# Cases

The public record of this project, kept by the Editor role. One entry per shipped
milestone, newest first. Each entry is three lines and carries a number. This is
the raw material for a talk, a post, or a lecturer's slide.

Format:
```
## YYYY-MM-DD · <milestone in five words>
- Problem: <what was wrong or missing, for whom>
- Decision: <what was chosen, and the alternative rejected>
- Result: <the number> · Lesson: <one sentence a lecturer could quote>
```
